# Копилка продуктовых идей

Учебный проект по инфраструктуре и администрированию.
Приложение на FastAPI для сохранения продуктовых идей:
названия и короткого описания.

## Подготовка

Нужен Python 3.12. Команды для Ubuntu / WSL:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Команды выполняются из папки проекта.

## Запуск

```bash
python -m uvicorn app_final:app
```

После запуска:

- форма добавления идей: http://127.0.0.1:8000/
- документация API: http://127.0.0.1:8000/docs

Для разработки можно добавить `--reload`, чтобы сервер
перезапускался при изменении кода. Остановка — Ctrl+C.

## Проверка

```bash
curl http://127.0.0.1:8000/health
curl http://127.0.0.1:8000/version
```

Для добавления идеи откройте главную страницу, заполните
название и описание, нажмите «Сохранить».
В ответ появится номер созданной идеи.

Название обязательно, максимум 100 символов.
Название из пробелов не принимается.
Описание необязательно, максимум 1000 символов.

Запись также можно создать через POST /ideas в /docs.

## Ограничения

Идеи хранятся в памяти и исчезают после перезапуска приложения.
Просмотр всех идей: http://127.0.0.1:8000/ideas
Просмотр одной идеи: http://127.0.0.1:8000/ideas/1
Если номер не найден, API возвращает 404.

## Если не работает

- Нет связи с сервером: проверьте, что команда запуска
  продолжает работать в отдельном терминале.
- Порт 8000 занят: остановите предыдущий сервер или запустите
  приложение с аргументом `--port 8001`.
  Тогда открывайте адрес с портом 8001.
- Ошибка 422: проверьте название и длину полей.
- Сообщения о запуске и запросах выводятся в терминал сервера.

## Основа проекта

За основу взят учебный пример app_final.py.

## Настройки и логи

APP_NAME — название приложения в документации /docs.
По умолчанию: «Копилка продуктовых идей».
Пример настройки находится в .env.example.

Запуск с другим названием:

```bash
APP_NAME="Моя копилка идей" python -m uvicorn app_final:app
```

Файл .env автоматически не загружается.

Логи видны в терминале сервера. При создании идеи выводится
сообщение Created idea id=... с номером записи.

## Тесты

Установка зависимостей для тестирования в активном окружении:

```bash
python -m pip install -r requirements-dev.txt
```

Запуск:

```bash
python -m pytest -v
```

Тесты проверяют служебные маршруты, создание и просмотр идей,
несуществующий номер и проверку названия.
Запускать Uvicorn для тестов не нужно.
Данные тестов очищаются между проверками.
